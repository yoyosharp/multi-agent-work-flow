# Sources read 2026-11-21 (Asia/Bangkok date; crawls 2026-11-21 UTC)
All via web index (browser_search / browser_open), except Studio, Temporal Web UI, Airflow UI, Linear Inbox/Triage opened via browser_open index fetch — flagged "index" not live-browser verified. No product UIs were logged into; claims are from official docs/product pages as cited.

- LangGraph HITL: https://docs.langchain.com/oss/python/langchain/human-in-the-loop ; https://docs.langchain.com/oss/python/langchain/frontend/human-in-the-loop ; https://docs.langchain.com/oss/python/deepagents/human-in-the-loop — approve/edit/reject/respond, review card, resume.
- Agent Inbox (LangChain example/DeepWiki secondary): https://deepwiki.com/langchain-ai/agent-inbox-langgraph-example/4-agent-inbox-integration — interrupted threads table, Accept/Edit/Respond/Ignore per HumanInterruptConfig.
- AutoGen Studio: http://microsoft.github.io/autogen/0.4.7/user-guide/autogenstudio-user-guide/usage.html — Team Builder canvas (team node + agent nodes, drag-drop / JSON toggle), Playground: inner monologue, metrics turn/token, artifacts, Gallery.
- CrewAI: https://docs.crewai.com/v1.15.21/en/observability/tracing ; https://docs-platform.crewai.com/platform/en/features/traces ; https://docs.crewai.com/v1.15.10/en/concepts/flows — AMP Traces tab: execution summary tokens/cost/time, tasks & agents, final output, execution timeline, detailed task view; Flow plot() -> single HTML file, nodes+directed edges.
- Temporal: https://docs.temporal.io/web-ui ; https://temporal.io/blog/lets-visualize-a-workflow ; https://docs.temporal.io/develop/go/platform/enriching-ui — Workflows table + Saved Views/filters, History views Timeline/All/Compact/JSON, Timeline spans grouped events, colour outcome, retry icon, Pending Activities tab with count badge, Relationships tree, Signals from UI.
- OpenAI tracing: https://openai.github.io/openai-agents-python/tracing/ ; https://developers.openai.com/api/docs/guides/agents-api/tracing — Traces dashboard, trace=workflow, spans nested (agent/generation/function/guardrail/handoff), session>turn>step timeline, click span for inputs/outputs/duration/status, filters by model/status/date.
- Airflow: https://airflow.apache.org/docs/apache-airflow/2.8.4/ui.html ; http://apache-airflow-docs.s3-website.eu-central-1.amazonaws.com/docs/apache-airflow/stable/ui.html — DAGs list with succeeded/failed/running counts, pause toggle, tags filter; Grid (rows=tasks, cols=runs, coloured cells, duration bar chart on top), Graph, Gantt, Calendar, Code; click cell -> details panel, Mark success/failed/Clear.
- Prefect: https://prefect-284-docs.netlify.app/ui/flow-runs/ ; https://www.prefect.io/docs/v3/advanced/interactive — Flow Runs dashboard filters (date/state/name/tags), run history by time/duration, rows with state/start/elapsed/completed task count; run detail: Radar -> replaced by timeline/flow-run graph, logs/task/subflow; pause/suspend with wait_for_input renders typed form + markdown description in UI, Resume button.
- Dagster: https://github.com/ssup2/dagster/blob/HEAD/docs/docs/guides/operate/webserver.md ; https://dagster-university.vercel.app/dagster-essentials/lesson-3/4-viewing-run-details — Overview/Runs filtered list, Asset catalog + Global asset lineage graph, Job Overview graph of ops; Run details: stats header, Gantt (upper-left) duration per step, bottom filterable structured vs raw logs, Errored section, re-execute.
- GitHub Actions: https://docs.github.com/en/actions/how-tos/monitor-workflows/use-the-visualization-graph — per-run real-time graph, job nodes, status icon left of name, lines=dependencies, click job -> log; steps not nodes.
- GitLab CI: https://docs.devnetexperttraining.com/static-docs/GitLab-CI-CD/pipelines/ (docs.gitlab.com mirror) ; https://gitlab.ipsemg.mg.gov.br/help/ci/pipelines.md — stages columns grouping jobs, full graph vs mini graph (index/commit/MR), grouping by stage or needs, hover failed job shows reason, play button to run manual job from graph.
- Argo: https://argo-workflows.readthedocs.io/en/latest/walk-through/dag/ ; https://docs.skyhook.io/application/jobs/argo-workflows (secondary for UI) — DAG tasks with dependencies, failFast; UI: executions list Pending/Running/Succeeded/Failed, detail: node counts, current/failed nodes, step progress, per-step logs, DAG view + timeline + artifact browser; suspend template exists in engine.
- GitHub PR review: https://docs.github.com/en/pull-requests/concepts/giving-reviews ; https://docs.github.com/en/pull-requests/how-tos/review-pull-requests/reviewing-proposed-changes-in-a-pull-request — Comment/Approve/Request changes submit, pending review batching, Files changed + Viewed checkbox per file + progress bar, sidebar linked issues/projects/milestones, merge box prerequisites (secondary via search summaries).
- Linear: https://linear.app/docs/inbox ; https://linear.app/docs/triage?_rsc=1pb9v ; https://linear.app/docs/my-issues ; https://linear.app/docs/parent-and-sub-issues?_rsc=1e0jx ; http://Linear.app/changelog/2025-04-03-collapsed-issue-history — Inbox Priority tab, snooze H, mark read U, mark-all, quick search, badge/grouping config, 2000 cap; Triage accept 1 / decline 2 / duplicate 3 / snooze H with optional comment; My Issues curated priority grouping; issue detail main column + properties sidebar, sub-issues progress, activity feed interleaving history+comments, collapsed similar consecutive history events.
